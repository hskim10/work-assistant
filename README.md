# 업무 비서 (work-assistant)

통화 녹음 받아쓰기, 메일, 메신저 대화, 회의록을 넣으면 Claude가 내용을 읽고
**할 일**, **일정**, **정리 노트**를 만들어 주는 웹 앱입니다.

## 기능

- **자료 입력:** 텍스트를 붙여넣거나 `.txt` / `.eml` / `.csv` / `.md` 파일을 올립니다.
- **할 일:** 마감일, 우선순위, 요청자와 함께 정리됩니다. 완료 체크, 수정, 직접 추가도 됩니다.
- **일정:** 약속과 마감일을 날짜별로 모아 보여 주고, `.ics` 파일로 내보내 구글·아웃룩·애플 캘린더에 넣을 수 있습니다.
- **정리 노트:** 자료마다 요약, 핵심 정보(금액, 결정 사항, 조건 등), 관련 인물을 정리합니다.
- **백업:** 전체 데이터를 JSON으로 내보내고 불러올 수 있습니다.

## 사용법

1. `index.html`을 브라우저로 엽니다(설치나 빌드가 필요 없습니다).
2. **설정** 탭에 Anthropic API 키를 넣고 저장합니다. 키는 https://console.anthropic.com 에서 발급합니다.
3. **자료 입력** 탭에서 자료 종류를 고르고 내용을 넣은 뒤 **분석하기**를 누릅니다.

## 알아둘 점

- **통화 녹음은 받아쓰기한 텍스트가 필요합니다.** 음성 파일을 직접 분석하지는 않습니다.
  휴대폰의 통화 녹음 요약/받아쓰기 기능이나 클로바노트 같은 앱으로 텍스트를 만든 뒤 붙여넣으세요.
- **메일·메신저는 자동으로 가져오지 않습니다.** 필요한 내용을 복사해 붙여넣거나 파일로 저장해 올리세요.
- 데이터와 API 키는 이 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터를 지우면 사라지니 가끔 백업하세요.
- 분석할 때 자료 내용이 Anthropic API로 전송되며, 사용량만큼 API 요금이 나옵니다.
  설정에서 더 저렴한 모델(Sonnet, Haiku)을 고를 수 있습니다.
